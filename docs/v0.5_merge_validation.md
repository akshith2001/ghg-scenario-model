# v0.5.1 integration validation

The supplied v0.5 archive was integrated onto published commit `136f6d9`.
Existing corrected synthetic-grid code, tests, reports and reproduction scripts
were retained. New planning, data-loading and marginal-emissions modules were
added. The desktop source folder was not modified.

## Corrections and checks

- All 123 unittest tests pass, including the four module-level regional/price
  tests now exposed to unittest discovery and the previous grid regressions.
- Grid-side imports still include line losses. Daily mean-power inputs, failed
  convergence, independent nodal balance and overlapping-window reporting retain
  their published safeguards.
- A measured 24-hour emission-factor shape is supported with finite, nonnegative,
  positive-mean validation. It cannot be applied to daily-resolution inputs.
- Export settlement is `price - (1 - export_value_share) * abs(price)`.
  With the default share of 0.9, EUR 100/MWh settles at EUR 90/MWh and
  EUR -100/MWh settles at EUR -110/MWh. This is an assumed transaction spread,
  not a measured Luxembourg tariff. It removes the old negative-price subsidy
  for simultaneous imports and exports. The zero-demand, zero-generation,
  zero-storage regression now yields zero trades and zero energy cost.
- Failed fleet-dispatch solves raise an exception. Price-feedback output includes
  an explicit convergence flag and the undamped battery-capacity residual;
  an iteration-limit result must not be described as an equilibrium.

## Measured-input integration check

Both 2024 and 2025 regional-factor central cases solve on 8,760 hourly inputs.
The leap-day convention matches the imported source. Results, parameter values
and input/source hashes are saved in
`output/luxembourg_merged/central_validation.json`.

Reproduce from the repository root after installing the synthetic extra:

```bash
python scripts/validate_energy_merge.py --output outputs/energy_merge_validation.json
python -m unittest discover -s tests -v
```

These central checks use default costs with neither foresight derating nor price
feedback. They test integration, not all original empirical claims.

## Research limitations and release boundary

The imported report and `figures/legacy_v0.5` are historical. Full uncertainty,
battery break-even, out-of-sample and price-feedback studies must be rerun before
their numbers can be cited as merged-version findings. The regional regression
is observational; its bootstrap currently resamples differenced days independently,
which does not establish valid time-series confidence coverage. Storage dispatch
uses an LP relaxation and estimated price curves; these remain modelling
assumptions rather than validated market-equilibrium or operational predictions.

The existing one-page research summary describes the previously published
synthetic-energy work and has not been expanded to claim these new results.
